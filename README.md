# 프로젝트 버전 관리 도구 Git-GitHub
Git : 파일의 변경 이력을 관리하는 버전 관리 도구
GitHub : Git 저장소를 인터넷에서 보관/공유하는 서비스
Git의 핵심은 누가, 언제, 무엇을, 왜 바꿨는지 기록하는 것이다.

## Git의 핵심 개념 
1. Working Directory : 내가 실제로 파일을 수정하는 곳
2. Staging Area : 다음 저장에 포함할 파일을 준비하는 곳
3. Repository : 변경 이력이 저장되는 곳
4. Commit : 변경 사항을 하나의 기록으로 저장
흐름 : 파일 수정 -> git add -> Staging Area -> git commit -> Repository

## Commit이 중요한 이유
Commit은 쉽게 말하면 세이브 포인트이다.

## GitHub는 무엇인가
Git은 내 컴퓨터에서도 혼자 사용할 수 있다.
GitHub는 그 Git 저장소를 원격에 둘 수 있게 해준다.
Git은 버전 관리 기술, GitHub는 Git 저장소를 올려두는 원격 서비스

## Git에서 자주 보는 기본 흐름
1. git init : Git 저장소 시작
2. git status : 현재 변경 상태 확인
3. git add : commit할 파일 준비
4. git commit : 변경 이력 저장
5. git log : commit 기록 확인
6. git clone : 원격 저장소 복사
7. git push : 내 변경사항을 GitHub로 올림
8. git pull : GitHub 변경사항을 가져옴
